# IK Sirius P14U · Rollbibliotek v0.3 (demo)

Öppna `index.html` i en webbläsare eller publicera hela mappen via GitHub Pages.

- `index.html`: startsida med rollkort, filter och formationer.
- `roller/*.html`: nio rollbeskrivningar med sex skeden vardera.
- `assets/style.css`: stil och dark mode baserat på Sirius profil (lokala semantiska tokens).
- `assets/app.js`: tema- och formationsväxling.

Innehåll: sju roller från `mitt-spelsystem(3).pptx` och två kompletterade arbetsversioner (Ytterback, Ytterspelare) utifrån TSW och Sirius Akademis rollmaterial. Kontrollera de senare före användning som fastställd utbildning.

Detta är en fristående demonstrationsprototyp, inte en officiell publicerad produkt.

## GitHub Pages
Lägg hela innehållet i repo-roten, aktivera Settings → Pages → Deploy from a branch → main → root. Sidan är statisk utan byggsteg eller backend.
